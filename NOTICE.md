# Attribution and project provenance

SnapReply is an independently authored implementation of a user-initiated screenshot → vision API → draft → clipboard workflow.

The user experience was inspired by the public description of [rishiv7/relay](https://github.com/rishiv7/relay). That repository had no explicit software license when inspected in October 2026. We do **not** redistribute the original `Relay.shortcut` binary, README, or implementation code. All executable source here was written separately for SnapReply.
